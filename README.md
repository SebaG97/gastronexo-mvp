# Gastronexo MVP

Base monorepo para una consola operativa de gestión gastronómica.

## Desarrollo local

```bash
docker compose up -d postgres
cd backend
npm install
npm run dev
```

En otra terminal:

```bash
cd frontend
npm install
npm run dev
```

## Inicio rápido

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
npm install
npm run dev
```

## Build de producción

```bash
cd frontend
npm run build
```

La documentación de diseño y alcance está disponible en `docs/`.
